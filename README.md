# Реестр доступов к предприятиям

Внутренняя веб-утилита для безопасного хранения доступов к предприятиям (VPN, SSH, Базы данных).

## Стек технологий
- Платформа: .NET 10.0 (ASP.NET Core Razor Pages)
- СУБД: MySQL 8.0
- ORM: Entity Framework Core 9.0

## Инструкция по локальному запуску

### 1. Предварительные требования
На целевой машине должны быть установлены:
- .NET 10 SDK
- Docker и Docker Compose

### 2. Запуск базы данных
В корневой папке проекта разверните контейнер с MySQL:
```bash
docker compose up -d
```

### 3. Применение миграций и запуск приложения
Откройте проект в Visual Studio или выполните команды в терминале:
```bash
dotnet run
```
После этого приложение будет доступно по локальному адресу.
